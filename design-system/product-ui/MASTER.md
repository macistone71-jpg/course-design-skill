# 智备课｜UI Design System Master

## 产品机制

教师将课程简报与来源转为“目标—活动—评价”一致的教案包，经质量门禁、教师审核与教研审核后导出。UI 的首要任务是让来源、过程、阻断和审核状态可信可见。

## 产品签名

- 版式：暖纸张底色上的教研编辑台，表单与课程结果左右分层；
- 信息：8 维质量环、SOURCE_GAP、目标—活动—评价映射；
- 交互：课程生产步骤轨 + 教师/教研双重审核。

## Tokens

- Ink `#19201d`；Paper `#f5f2ea`；Surface `#fffdf8`；Primary `#174c3c`；Accent `#d7f169`；Warning `#ad7027`；Danger `#ad3c32`；
- 圆角克制：表单 4–6px，状态 pill 可用全圆；
- 间距遵循 4/8 系统；正文中文行高 1.6–1.8；
- 标题可用宋体表达教研感，正文使用系统无衬线确保可读性。

## Accessibility / Responsive

- 交互焦点 3px amber，不能只靠边框变色；
- 按钮最小高度 44px；
- 390px 不允许水平滚动；
- reduced-motion 下关闭平滑滚动与非必要动画；
- sticky header 不得遮挡键盘焦点。

## 禁止

虚构教师效果指标；AI 草稿显示为“已发布”；无来源仍通过；用幼儿化插画覆盖专业教师场景；用装饰性 AI 紫粉渐变替代教研机制。
