# 课程设计 Skill

> 把一个知识主题设计成一门结构清晰、能落地交付的线上课程。

## 这是什么

一个可落地的 Skill。手里有一块知识、一个技能、一段经验，想把它做成线上课程时，用它把「一堆内容」设计成「一门能学得会、学得完的课」。

**核心认知**：课程设计不是「把知识罗列一遍」，而是「帮学员从不会到会」。

## 五步设计法

1. **定目标学员**：这门课是给谁上的（岗位、水平、痛点、动机）
2. **定学习目标**：学完之后「能做什么」，而不是「知道什么」
3. **搭课程结构**：把学习目标拆成几节课
4. **写每节要点**：每节课讲什么、怎么讲
5. **设计练习**：每节练习 + 结课作业，检验目标达成

## 怎么用

1. 打开 `SKILL.md`，里面有完整的操作框架、步骤、模板和检查清单
2. 把它当「操作手册」：接到对应工作时，照着步骤一步步走
3. 可以直接复制里面的「输出模板」，填入你的实际内容
