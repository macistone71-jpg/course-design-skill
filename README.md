# AI 备课工作流

> 人机协作备课：AI 生成大纲、教案、讲稿的初稿，人负责审核和打磨。把备课从 3-6 小时降到几十分钟。

## 项目定位

这是一个「AI + 教育」的产品方案，源自我在线上教育公司的真实工作场景。

作为产品经理，我观察到备课是老师最大的隐性时间黑洞——一节课要花 3-6 小时，其中大部分时间耗在「组织内容」而不是「设计教学」。而 AI 恰好擅长「组织内容」。

这个项目把「备课」重新设计成一个人机协作的工作流：**AI 做生产，人做决策**。

## 解决的痛点

| 痛点 | 现状 | 方案 |
|------|------|------|
| 备课耗时 | 一节课 3-6 小时 | 降到几十分钟 |
| 时间错配 | 老师把时间花在「组织内容」 | 把时间还给「设计教学」 |
| 质量不稳 | 备课质量靠老师个人状态 | Prompt 模板 + 检查清单保证下限 |

## 核心设计：人机分工

```
AI 做（快，但可能平庸）         人做（慢，但决定质量）
├─ 生成课程大纲                  ├─ 教学目标判断
├─ 生成逐节教案                  ├─ 学情适配
├─ 生成讲稿                      ├─ 内容审核
└─ 生成练习题                    └─ 加真实案例 + 打磨
```

**这是所有「AI + 专业工作」的通用范式**——AI 负责规模化生产，人负责判断和把关。这个范式可以迁移到任何行业。

## 五步工作流

1. 明确输入（人）：学员画像、学习目标、时长形式
2. AI 生成大纲（初稿）
3. 人工审核大纲（砍掉凑数的，补上遗漏的）
4. AI 逐节生成教案和讲稿（逐节生成，质量可控）
5. 人工打磨（加案例、调语气、补实战细节）

## 项目亮点

- **可落地的 Prompt 模板**：3 个可直接复用的备课 Prompt，附质量检查清单
- **人机协作的产品思考**：不是「AI 替代人」，而是「AI 干重复的，人干判断的」
- **可迁移的方法论**：这套人机协作范式，同样适用于 AI 写作、AI 设计、AI 编程等场景
