# 智备课 MVP：从 Skill 到上线产品

## 产品目标

把 `ai-lesson-planner` 的企业级方法论落成教师可直接操作的响应式 Web MVP。产品不把“生成长文”当完成，而是把 LessonBrief、Source Pack、目标反向设计、课堂活动、形成性评价、质量门禁和人工审核串成闭环。

## MVP 成功标准

1. 教师可在 3 分钟内完成课程简报并生成结构化课程包。
2. 每个目标都被课堂活动和形成性评价覆盖。
3. 未提供来源时必须触发 `SOURCE_GAP` 硬门禁。
4. AI 草稿不能直接变成发布状态，必须经过教师与教研审核。
5. 支持本地保存、Markdown 与 JSON 导出。
6. 手机和桌面端均可完成核心流程。

## 灰度计划

- 用户：5–8 名一线教师，覆盖小学/初中、文科/理科。
- 任务：每人使用真实主题完成 1 节 45 分钟教案。
- 观察：首次生成耗时、表单卡点、草稿采用率、人工修改点、来源补充率、是否理解质量门禁。
- 访谈问题：哪一步最省时？哪段最不可信？是否愿意把真实教材放入？导出格式是否可直接进入现有工作流？
- 退出条件：严重阻塞为 0；核心任务成功率 ≥80%；教师明确知道“AI 草稿 ≠ 已审核教案”。

## 上线后指标

只记录真实数据，不虚构：创建到生成耗时、保存率、导出率、来源填写率、硬门禁失败率、教师提交审核率、主要修改原因、一次教研通过率。
