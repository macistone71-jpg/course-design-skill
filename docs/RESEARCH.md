# 智备课行业与竞品速研

## 用户与场景

核心用户为一线教师与教研员。高频任务不是“得到一篇文章”，而是把课程标准、教材内容与真实学情转成能上课、能检查、能复用的课程包。主要痛点：

1. 输入材料分散，教师需要在课标、教材、旧教案和网络资料间反复搬运。
2. 通用模型容易写得流畅但缺少来源，甚至虚构标准编号。
3. 教学目标、课堂活动与评价常常互不对应。
4. 初稿易得，但事实核验、差异化与修改仍耗时。
5. 缺少“AI 初稿—教师审核—教研审核”的责任边界。

## 竞品观察

| 产品/案例 | 可借鉴能力 | 本产品取舍 |
|---|---|---|
| MagicSchool | 面向教师的场景化工具集合；课标与目标进入生成入口；强调教师节省时间 | MVP 先聚焦完整备课链路，不扩张为 80+ 独立工具 |
| Eduaide | 从目标、课程材料、网站/视频与标准生成；同一工作区内评价年级适配、修改和导出 | 借鉴“引导式表单 + 生成后检查”，强化来源缺口与目标映射 |
| Diffit | 阅读材料分级与差异化支持 | 在教案中提供支架、核心与挑战三层建议，后续再做材料分级 |
| Kuraplan | 课程框架 grounding，降低虚构标准代码的风险 | 不自动生成未核验标准代码；来源由教师提供并明确登记 |
| 通用聊天模型 | 自由度高、探索快 | 仅作为未来可插拔生成引擎；产品工作流负责约束、检查与审核 |

## 差异化定位

**一句话：** 给重视教学质量与审核责任的教师，一套“有来源、有目标对齐、有质量门禁”的 AI 备课工作台。

不是：
- 一次点击生成漂亮长文；
- 未经核验自动匹配课程标准代码；
- 自动替教师决定教学是否可用；
- 用虚构节省时长或学习效果作为营销证据。

## MVP 机会

1. 用 LessonBrief 限定“教给谁、教到什么程度”。
2. Source Pack 把用户材料转成可追溯来源；缺少来源就硬拦截。
3. 强制每个目标同时绑定活动与评价。
4. 质量报告解释“为什么能/不能进入人工审核”。
5. 课程包导出为 Markdown 与 JSON，兼容教师现有文档工作流和后续 LMS 接入。
